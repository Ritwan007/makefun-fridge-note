One funny passive-aggressive note a smart fridge leaves for its owner — a
[make.fun](https://make.fun/competitions/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7) entry.

## The note

> You hid the chocolate behind the vegetables. I saw. The vegetables saw. We are both disappointed.

## How it works

`main.py` writes that single line to `/output/entry.txt` (1–200 chars, UTF-8,
non-blank). Run it with:

```sh
python3 main.py
```
